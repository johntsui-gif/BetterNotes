BetterNotes feature status

6 November 2026 · 13 not implemented, 26 implemented, 34 partial. Read each limitation below; this is not full Goodnotes parity.

Back to BetterNotes · Full release notes and validation

FeatureStatusImplementation or gap
Input Hardware — Apple Pencil Pro SqueezeNot implementedApple Pencil Pro squeeze needs native Apple Pencil integration. A dependable browser event is not exposed by the current app stack; no pretend toggle is included.
Input Hardware — Apple Pencil Pro Barrel RollNot implementedBrowser PointerEvent rotation support is not a guarantee of Apple Pencil barrel-roll delivery. Native integration and hardware validation are needed; pressure alone is supported.
Input Hardware — Mouse and Trackpad SupportImplementedMouse drawing, scrolling, right-click object selection, keyboard shortcuts and object commands.
Palm Rejection — Automatic RejectionPartialStylus-only drawing and rejection of large touch contacts. This is a browser-level heuristic, not Goodnotes-quality palm classification. Physical stylus testing remains necessary.
Palm Rejection — Posture ConfigurationPartialLeft/right dominant-hand preference changes command alignment. No graphical posture classifier or predictive palm region model.
Palm Rejection — Sensitivity LevelsPartialStylus-only and Ignore stylus options, plus fixed large-touch rejection. Three calibrated palm sensitivity levels require real-device validation and are not provided.
Pen Tool — Fountain PenPartialPressure-varying vector strokes with a response control. No calibrated tip-sharpness, speed dynamics or barrel-roll nib model.
Pen Tool — Ballpoint PenImplementedConstant-width vector ballpoint strokes.
Pen Tool — Brush PenPartialPressure-sensitive brush width and response setting. Not a full calligraphic nib or tilt simulation.
Pen Settings — Stroke StyleImplementedSolid, dashed and dotted stroke styles in Tool settings.
Pen Settings — Color PresetsPartialColor picker and up to 12 editable hex presets. Presets are shared across tools; no eyedropper or separate per-tool palettes.
Pen Settings — Thickness PresetsPartialThree configurable width presets. Values are page coordinate units, not physically calibrated millimeters across screens.
Highlighter — Freehand HighlightImplementedTranslucent highlights render beneath other marks within their layer.
Highlighter — Draw in Straight LinePartialOptional horizontal/vertical snapping when the stroke finishes. No graduated stabilization slider or intent classifier.
Eraser Tool — Standard EraserPartialRadius-based erasing of BetterNotes ink. It cannot erase handwriting baked into an imported PDF or image. Standard behavior uses the stroke mode rather than a separate bitmap eraser.
Eraser Tool — Precision EraserPartialSplits sampled freehand strokes around the eraser. This is vector segment removal, not exact pixel subtraction; rotated objects and source PDF ink are not precision-erased.
Eraser Tool — Stroke EraserImplementedDeletes touched strokes on the active layer, respecting locks and the highlighter filter.
Eraser Settings — Auto-DeselectImplementedOptional return to the previous writing tool after erasing.
Eraser Settings — Erase Highlighter OnlyImplementedRestricts erasing to BetterNotes highlighter marks.
Tape Tool — Hide ContentImplementedOpaque tape strokes hide answers; current color and width control new tape.
Tape Tool — Custom PatternsImplementedInsert & study → Tape appearance imports a repeating image pattern. Images are normalized to PNG.
Tape Tool — Reveal ContentImplementedTap tape in Read mode to reveal/re-cover. Remove all tape is available under Insert & study. Exported tape remains covered.
Lasso Tool — Freehand LassoImplementedFreehand lasso selects objects by their bounds center on the active layer, with type filters. This is geometric selection, not semantic handwriting selection.
Lasso Tool — Rectangular LassoImplementedRectangular selection with the same filters.
Lasso Actions — Object ManipulationPartialMove by dragging, resize/rotate numerically, copy/cut/paste/delete/recolor, PNG selection export, front/back and left/center/top alignment. No resize/rotate handles or full alignment/distribution suite.
Lasso Actions — Contextual ConversionPartialEditing selected text and sticky notes is available. Handwriting-to-text and handwriting-to-math need recognition models, language support and evaluation; not implemented.
Layers — Layer ManagementImplementedFive named layers, active-layer editing and show/hide controls. Layer panel is opened or dismissed as needed.
Layers — Collaborative VisibilityPartialVisibility is local to the current browser session. Real-time collaboration and collaborator-specific settings do not exist.
Object Control — Object LockingImplementedImages, shapes, text, sticky notes and tape can be locked/unlocked. Handwriting and highlighter ink are excluded. Locked objects cannot be moved or erased.
Object Control — Arrange OrderImplementedFront/back ordering within layer ordering. Highlighters intentionally remain below other marks.
Elements — Asset LibraryImplementedNamed reusable selections, collections, rename/delete and insertion. Stored as a syncable elements notebook.
Elements — GIPHY IntegrationNot implementedGIPHY search needs an API integration, credentials, service terms and attribution. Local GIF import is converted to a static image; animated canvas assets are not supported.
Notebooks — Dynamic TemplatesImplementedBlank, lined, grid and dotted templates; paper/line colors, spacing, A4/Letter/landscape/square sizes. Templates apply to blank pages, not an imported PDF background.
Notebooks — Page ManagementImplementedAdd/delete/restore/duplicate/reorder pages, drag reordering, first/last/previous/next and direct page jump. PDF source-page mappings stay attached to pages.
Whiteboards — Infinite CanvasPartialExpandable finite whiteboard with zoom and scroll, up to a 20,000-unit dimension threshold. A truly unbounded, tiled canvas requires a different renderer and spatial indexing.
Whiteboards — Minimap NavigationPartialClickable minimap, fit and expand controls. No drag viewport, double-tap fit or separate visibility preference.
Text Documents — Block-Based TypingPartialReorderable paragraph/headings/list/quote/code blocks, block-wide bold/italic/strikethrough and HTML export. Editing happens in a text dialog rather than a full inline rich-text editor.
Text Documents — Tables and MediaPartialTab-separated editable tables, image blocks and external video links. No slash-command menu, embedded video player or diagram editor.
Study Sets — Flashcard CreationPartialTyped questions/answers, image attachments, reveal, edit/delete, basic review intervals and due-first sorting. Freehand card authoring and advanced adaptive scheduling are not implemented.
Study Sets — Bulk ImportImplementedCSV/TSV/TXT question-answer import, including quoted commas/newlines; CSV export. TXT is interpreted as tab-delimited columns. Use headerless input.
Stylus Gestures — Scribble to EraseNot implementedScribble recognition needs a tested classifier to distinguish correction gestures from actual handwriting. Destructive guesswork would risk notes; use Eraser instead.
Stylus Gestures — Circle to LassoNot implementedCircle-and-hold classification is not implemented. It needs a gesture state machine and stylus testing to avoid converting intentional circles into selections.
Stylus Gestures — Draw and Hold ShapeNot implementedDraw-and-hold shape recognition is not implemented. Explicit line/rectangle/ellipse/arrow tools are available; robust recognition is additional engineering, not a platform impossibility.
Touch Gestures — Double Tap to UndoNot implementedTwo-finger double-tap undo needs a tested multi-touch gesture arbiter to avoid collisions with scrolling and palm contacts. Toolbar and keyboard undo/redo work.
Navigation — Scrolling DirectionPartialScrollable current page plus explicit page navigation. No continuous multi-page vertical viewer or horizontal swipe/page-flip mode; that requires virtualized page layout and annotation routing.
Navigation — Zoom WindowNot implementedA separate writing zoom window with auto-advance requires two synchronized editable viewports and handwriting position tracking. Standard zoom is available.
Navigation — SidebarPartialCollapsible page organizer, lazy PDF page thumbnails, annotation/template miniatures, page labels and clickable PDF outline. Audio bookmarks have their own dialog; no unified sidebar tabs.
Navigation — Read-Only ModePartialRead mode disables drawing, enables PDF text selection and links, and allows tape reveal. Editing tools remain visible for switching modes rather than hiding the entire toolbar.
Multi-Window — Split View SupportPartialMultiple document tabs and separate browser windows; users can tile windows using their OS. No native iPad Dock split gesture or integrated two-document split pane. Avoid concurrently editing the same notebook in multiple windows.
Drag and Drop — Page TransferNot implementedCross-window page drag/drop with multi-page stacks is not implemented. Correct transfer must bring source PDF resources, annotations and stable link targets across documents; use editable backups and notebook merge instead.
Drag and Drop — Lasso TransferPartialLasso copy/cut/paste works across same-origin BetterNotes windows through a local clipboard. Physical cross-window drag/drop is not implemented.
Customization — Toolbar LayoutImplementedTool settings supports drag ordering and hiding tools; Read and Lasso remain available. Audio is a fixed workspace action.
Customization — Floating Menu DockingPartialTop/left/right toolbar docking via settings on large screens; compact layout on phones. No freely draggable secondary floating palette.
Customization — Undo/Redo PlacementImplementedLeft/right undo-group placement setting.
Handwriting AI — SpellcheckNot implementedHandwriting spellcheck and corrections in the user's writing style require recognition, language models and handwriting synthesis. No suitable validated offline model is bundled; paid/backend AI has not been provisioned.
Handwriting AI — Word CompleteNot implementedLive handwriting word completion requires low-latency recognition and personalized stroke synthesis. This is not supplied by a static website or the PDF viewer.
File Structure — Custom FoldersPartialNested folder paths, rename, document movement, local emoji/color styling, folder-to-Trash action. Empty folders and appearance metadata remain local rather than syncing as independent Drive entities.
File Management — Move and MergeImplementedNotebook settings moves a document to a folder. Merge creates a new notebook and retains originals. Source PDF outlines are not transferred to merged notebooks.
File Management — Trash BinPartialRecoverable notebooks, folder contents and pages; per-item purge. Empty folder records themselves are not recoverable items. Purge does not erase older cloud revisions or downloaded backups.
Search — Universal SearchPartialLibrary title search plus Search contents scans text objects, text documents, study sets and extractable PDF text. It is an on-demand scan, not a background full-text index.
Search — Handwriting OCR SearchNot implementedHandwriting/scanned-image OCR and language indexing need a recognition engine, model assets, background indexing and accuracy tests. PDFs with an existing text layer are searchable.
Security — Password ProtectionNot implementedNo password protection or document encryption. Secure delivery needs authenticated encryption, key derivation/recovery, locked search/thumbnails, encrypted sync and backup exclusion throughout the data lifecycle. A cosmetic password prompt would not protect the data.
Synchronization — Google Drive SyncPartialExisting two-way Drive revisions, scheduled polling while open and conflict copies are retained. It is not instantaneous collaboration, does not run with the app closed, and an open notebook must be reopened to accept remote changes. OAuth client setup/reconnection is still required.
Backup — Auto-BackupPartialNew one-way dated snapshots in a separate BetterNotes Backups Drive folder. No Dropbox, OneDrive or WebDAV connector; each needs its own authorization, API and CORS/deployment support.
Backup — Auto-Backup FormatImplementedDrive snapshots include flattened PDF for notebooks/boards and editable BetterNotes backups for all workspace types.
Backup — Backup FrequencyPartialConfigurable 1–168-hour interval, default 24 hours, checked while the app is open and authorized. Browser/OS suspension and token expiry prevent guaranteed unattended backups.
Import — File IngestionPartialPDF, JPEG/PNG, nested ZIP and BetterNotes backups. Native .goodnotes packages and Word/PowerPoint imports are not supported. Reliable Office rendering needs a conversion service or a substantial renderer; exporting to PDF is the current route.
Export — Format SelectionImplementedNotebook PDF, current-page PNG, editable backup, folder ZIP; text-document HTML and study-set CSV.
PDF Export — Flattened PDFPartialRasterized single-image pages with backgrounds/annotations included or excluded; no source hyperlinks. No OCR layer or handwriting-recognition export option.
PDF Export — Editable PDFPartialVector-preserving export retains source PDFs and adds basic ink, shapes and Latin text as page-content vectors. Complex/rotated/non-Latin objects may rasterize. It does not create fully editable standard PDF ink-annotation objects, expose source annotations for editing, or guarantee third-party editability. Outlines and original internal links are retained only for unchanged source page order; removed on reordered/deleted/duplicated exports to avoid wrong destinations. Source PDF annotations are part of the source background toggle.
Export Options — Folder ExportImplementedFolder ZIP exports preserve paths and empty folders; choose PDFs or editable backups. Unique filename suffixes avoid overwriting duplicate notebook titles.
Hyperlinks — Internal LinkingPartialSelected objects link to stable page IDs in the same notebook. Links work in Read mode and vector PDF export; cross-notebook links are not implemented.
Hyperlinks — External LinkingImplementedSelected objects can link to HTTP/HTTPS URLs. PDF viewer handles source links; vector export includes new links. Flattened export intentionally loses links.
